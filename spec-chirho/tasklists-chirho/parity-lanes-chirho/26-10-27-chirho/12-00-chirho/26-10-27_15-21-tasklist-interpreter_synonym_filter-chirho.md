and dependency paths. Branch `interpreter-synonym-filter-chirho` from main d6ec2a12, fast-forwarded

## Residuals (not row 668)

- **A multi-module ground predicate.** `fiveChirho :: CellChirho; fiveChirho = 5` for a
  `data CellChirho` with no `Num` instance:
  - GHC rejects it (GHC-39999), and single-module `check` refuses it (E0204).
  - As a two-module program it is accepted on all three engines, which print `41`, with or without
    any synonym. This is row 662's area.
- **A native cross-module derived Show.** `print` of a derived-`Show` value whose type is defined
  in another module fails at runtime on LLVM and Cranelift with `show: no native Show instance for
  a boxed value` (exit 1), with or without a synonym. The interpreter prints it exactly after row 668.
